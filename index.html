ETL · WINDOW FUNCTIONS · AIRFLOW
CDC Chronic Disease Indicators ETL
Extract → transform → analyze pipeline over CDC's BRFSS Chronic Disease Indicators. Separates raw and curated layers in SQLite, builds conformed dimensions, and runs analytical SQL with CTEs, RANK, PERCENT_RANK, LAG, and AVG OVER ROWS. An Airflow DAG re-uses the same Python functions as the CLI so scheduled and ad-hoc runs cannot drift.

BIGQUERY · GCP · CLOUD
NIH Funding Analysis on BigQuery
Cloud-connected research-funding analysis with parallel SQL dialects: identical analytical queries written for SQLite (local path) and BigQuery (cloud path) so reviewers can audit the cloud path against the local one. Ingests from the NIH RePORTER REST API, loads into BigQuery with WRITE_TRUNCATE idempotency, and demonstrates dialect-specific features like UNNEST + SPLIT for term unpacking.
2,000 NIH projects 236 institutions two dialects, 1 analytical contract

DUCKDB · RECURSIVE CTE · SCD TYPE 2
NYC Taxi 5-Layer Cleaning Pipeline
DuckDB pipeline over NYC Yellow Taxi trips that walks the data through profile → clean → dimensions → reshape → analytics. Showcases recursive CTEs for zone hierarchy traversal, Slowly Changing Dimension Type 2 with point-in-time as-of queries, PIVOT / UNPIVOT for wide↔long reshape, IQR-based outlier detection, and an 8-bit data-quality flag bitmask.
