## Projects
1. [Project 01: Tableau Heart Disease Dashboard](./project-01-tableau-heart-disease/README.md)
2. [Project 02: BRFSS Health Disparities in R](./project-02-brfss-health-disparities-r/README.md)
3. [Project 03: CFPB Debt Collection Complaints in Excel](./project-03-excel-debt-complaints/README.md)
4. [Project 04: Pennsylvania Hospital Performance in Power BI](./project-04-powerbi-pa-hospitals/README.md)
5. [Project 05: REDCap Liver Study Abstraction Database](./project-05-redcap-liver-study/README.md)

## Local website preview
Open the local static site at [site/index.html](./site/index.html).

## Build notes
- Most projects were implemented with reproducible scripts and local datasets so they can be transferred to GitHub or a personal site.
- The Tableau and Power BI outputs are prepared as dataset + dashboard specs and code resources because those software products require proprietary desktop clients to save `.twb` or `.pbix` files.
- The BRFSS and CFPB outputs use real source data downloaded locally in this workspace.
